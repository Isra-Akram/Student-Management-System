# Student Management System

## Description

A beginner-friendly Python Student Management System that allows users
to add, view, search, update, and delete student records.

## Features

- Add student
- View students
- Search student by roll number
- Update student marks and grade
- Delete student
- Exit the program
- Invalid choice handling

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional statements

## How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run `student_management.py`.
4. Follow the menu instructions.
